# Gradifine – Branding & Digital Marketing Agency

A high-performance, modern, and pixel-perfect website for **Gradifine**, a premier digital marketing and creative agency.

## 🚀 Features

- **Clean Minimalist Monochrome Design**: Deep obsidian backdrop (`#090A0E`) with luminous neon magenta / fuchsia accents matching the Gradifine 3D emblem.
- **Modern Hero Section**: High-impact typography, animated neon pulse badge, and responsive showcase CTA.
- **Full-Funnel Services Grid**: Performance Marketing, Web Development & UI/UX, SEO, and Social Media growth cards.
- **Client Portfolio & Showcase**: High-resolution project creatives with interactive lightbox modal.
- **Client Proof & Press Bar**: Media mentions ticker and dark-mode client logo showcase.
- **Verified Testimonials**: Verified client review cards with 5-star ratings.
- **Animated Impact Counters**: Dynamic counters for Team Members, Clients Served, and Client Retention.
- **Interactive Enquire Form**: Lead generation form with budget notice and instant validation feedback.
- **Floating Controls**: Integrated WhatsApp chat button, phone dialer, pinned "GET IN TOUCH" quick-scroll tab, and persistent Dark/Light theme toggle.

## 🛠️ Built With

- **HTML5**: Clean, accessible, semantic markup.
- **Vanilla CSS3**: Custom design tokens, responsive CSS grid/flexbox layouts, keyframe animations, KaTeX typography with League Spartan and Plus Jakarta Sans.
- **Vanilla JavaScript**: Lightweight, zero-dependency interactions, modal controllers, intersection observers, and theme management.

## 💻 Local Preview

Open `index.html` directly in any web browser, or run a local HTTP server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```
Visit `http://localhost:8000` in your browser.
